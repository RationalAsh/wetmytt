From idea to first draft in minutes

Prompt → Presentation

No template browsing or endless choices. Start with what you want to say.

  1. Start with your files

    Create a deck folder and add your images and reference material. Your HTML, CSS, JavaScript, and assets stay on your computer.

  2. Talk it into shape

    Ask AI for a first draft in minutes, or build it slide by slide. Refine the story, layout, and design through conversation.

  3. Tweak, present, share

    Click slide text to adjust the wording. Present full screen, or export a PDF with selectable text to send around.

Built for personal presentations

Spin up a quick presentation for those endless meetings without spending hours in PowerPoint.

Use the AI you already work with

Connect Codex or Claude Desktop to the app and use your existing agent account. Built-in chat is a separate option: bring an OpenAI, Claude, Gemini, or OpenRouter API key, or use a local Ollama model. Your agent's account and usage limits still apply.

HTML = infinite possibilities

AI edits the actual HTML, CSS, and JavaScript files. Your slides can have interactive elements, animations, code, video, and whatever the web has to offer. No Markdown conversion or fixed template catalog. Open the folder in your own editor whenever you like.

Local files, with a choice of AI connection

Decks and conversations stay on disk. Cloud AI receives the content sent to it; choose local Ollama for local inference. Presenting and PDF export work without an AI connection.

Still work in progress!

Mac downloads are available for Apple Silicon and Intel. This is an early build for personal use, with no shared editing, PowerPoint export, or presenter notes yet.

A personal project

Why I made this

I'm an academic, I do research in a lab, and I often lead teams. That means regular meetings. Without a presentation to anchor the discussion, those meetings can quickly drift towards chaos.

For years, I made my presentations in PowerPoint or Beamer. When AI workflows became more common, I tried using AI with PowerPoint and Google Slides. The results were often great, but the generated presentations were tough to edit manually, and iterative changes quickly became difficult. I'd run out of context, or have to download the presentation, edit it myself, and upload it again for the next round. Sometimes moving a single element would break the beautiful layout ChatGPT had made for me. Google Slides had similar issues.

I eventually started making one-off HTML presentations that I could just play in my browser. That worked really well, but I got tired of repeating the same prompt every time: “Help me create a website as a presentation. Follow these rules, include these UI elements…”

So I collected the patterns I kept using in those HTML presentations and baked them into this app. Now I can start with the conversation instead of explaining the setup all over again.
