**Welcome to My TED Talk 0.3.3** adds Gemini API key support and improves macOS update cache cleanup.

### Features and improvements

- **Use Gemini:** choose **Settings → AI connection → Gemini**, enter a Gemini model ID that supports tools, and paste your Google AI Studio API key. The endpoint is filled in automatically, and keys use the app's existing encrypted storage.
- **Flexible provider picker:** all five AI providers fit within the settings layout, including narrow windows.
- **Less update clutter:** after an update is installed, the app removes the matching pending archive and metadata while keeping files needed for differential downloads and any newer pending update.
- **Consistent branding:** the app header uses the shared project logo.

### Upgrading

Installed 0.3.1 and later builds can receive this release through automatic updates. Use **Check for Updates** in Settings, then **Restart to Update** when ready, or quit normally and reopen the app after the update downloads. Users on 0.3.0 or earlier should install the DMG manually.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.3.3-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.3.3-mac-x64.dmg`

Open the DMG, drag **Welcome to My TED Talk** into **Applications**, replacing the previous version if installed, then launch it from Applications. Node.js, npm, and a separate Git installation are not required.

The release also includes app ZIPs, blockmaps, and `latest-mac.yml` for automatic updates. Use the DMG for a manual installation.
