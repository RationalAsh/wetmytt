First release of **Welcome to My TED Talk**, a local desktop app for HTML slide decks.

- Create a deck from the starter or open an existing HTML presentation folder.
- Edit with built-in AI chat using your own provider credentials, or connect Codex.
- Click slide text to edit its JSON content.
- Present full screen and export slides to PDF.
- See file changes immediately in the live preview.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.1.0-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.1.0-mac-x64.dmg`

Open the DMG, drag **Welcome to My TED Talk** into **Applications**, then launch it from Applications. Node.js and npm are not required.

This is an early release. Built-in AI chat requires your own provider credentials or a local Ollama installation. The AI can edit files and run terminal commands with your user permissions.
