**Welcome to My TED Talk 0.3.1** adds automatic macOS updates, slide thumbnails, and a smoother editing workspace.

### New features and improvements

- **Automatic updates:** installed macOS builds check for updates at startup and every four hours, then download them in the background. Use **Check for Updates** in Settings to check manually. When an update is ready, choose **Restart to Update** or quit normally and reopen the app. Updates never force an unexpected restart.
- **Slide thumbnails:** browse slides with revision-aware previews and a reusable renderer that keeps thumbnails in sync with edits.
- **Recent presentations:** reopen folders from the compact recent list or File menu. External agents can discover recent presentations and create new starter projects through MCP.
- **Chat workspace:** refreshed conversation controls preserve local history. Settings now includes a configurable turn limit, with a default of 300 and a maximum of 1024 turns per request.
- **Workspace details:** the app displays its version and the current presentation's Git branch.

### Upgrading

Install this release manually if you are using 0.3.0 or earlier. This is the first release with automatic updates; subsequent stable releases can update automatically.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.3.1-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.3.1-mac-x64.dmg`

Open the DMG, drag **Welcome to My TED Talk** into **Applications**, replacing the previous version if installed, then launch it from Applications. Node.js, npm, and a separate Git installation are not required.

The release also includes app ZIPs, blockmaps, and `latest-mac.yml` for automatic updates. Use the DMG for a manual installation.
