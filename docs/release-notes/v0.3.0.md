**Welcome to My TED Talk 0.3.0** adds Claude Desktop connections, shared research and editing tools, and local version history for presentations.

### New features

- **Connect to Claude:** install the app's desktop extension from the toolbar to work on the open presentation in Claude Desktop. The extension uses Claude's bundled runtime; no separate Node.js installation is needed.
- **Research and assets:** built-in chat, Codex, and Claude share web search, readable page retrieval, local asset imports, and public asset downloads.
- **Precise file edits:** agents can apply validated unified patches to add, edit, rename, or delete presentation files.
- **Local version history:** new decks start with a Git repository and an initial commit. Agents can inspect changes, stage files, commit, and manage local branches. Git ships with the app on Apple Silicon and Intel Macs.

### Connection improvements

- After opening or switching presentations, agents can call `get_presentation` to select the current deck without reconnecting.
- Claude's bridge recovers sessions after app restarts or idle expiry. It requires a fresh presentation selection before continuing and does not automatically replay edits.

### Upgrading

Dedicated research, asset, file, and Git tools replace arbitrary terminal execution in built-in chat. MCP exposes the same dedicated tools.

After installing this version, use **Connect to Claude** and install the extension. If you previously installed a development copy, reinstall it to pick up the updated bridge. Keep the app running with a presentation open when using external agents.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.3.0-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.3.0-mac-x64.dmg`

Open the DMG, drag **Welcome to My TED Talk** into **Applications**, replacing the previous version if installed, then launch it from Applications. Node.js, npm, and a separate Git installation are not required. Install updates manually; auto-update is not configured.
