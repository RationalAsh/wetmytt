**Welcome to My TED Talk 0.3.2** improves macOS quitting, saved API key access, and workspace spacing.

### Fixes and improvements

- **Quit completely:** Cmd+Q explicitly quits the app, and Dock activation cannot reopen a window during shutdown.
- **Fewer Keychain prompts:** saved API keys stay locked until chat needs them. Settings, model changes, and startup no longer unlock the key unnecessarily. Guidance beside the API key field explains macOS Keychain access.
- **More room to work:** shorter top and Backstage headers and removed decorative footer text leave more vertical space for slides and chat.
- **Cleaner model chip:** removed the low-aligned chevron from the chat model selector.

### Upgrading

Installed 0.3.1 builds can receive this release through automatic updates. Use **Check for Updates** in Settings, then **Restart to Update** when ready, or quit normally and reopen the app after the update downloads. Users on 0.3.0 or earlier should install the DMG manually.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.3.2-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.3.2-mac-x64.dmg`

Open the DMG, drag **Welcome to My TED Talk** into **Applications**, replacing the previous version if installed, then launch it from Applications. Node.js, npm, and a separate Git installation are not required.

The release also includes app ZIPs, blockmaps, and `latest-mac.yml` for automatic updates. Use the DMG for a manual installation.
