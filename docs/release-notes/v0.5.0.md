**Welcome to my Talk 0.5.0** introduces the app's new name, a friendlier Edit tab, and complete macOS menus.

### Features and improvements

- **A new name:** the app is now called **Welcome to my Talk**. Your settings, saved API keys, recent decks, and Claude and Codex connections carry over unchanged.
- **A friendlier Edit tab:** see the current slide's fields with readable labels and controls that match the content, such as lists, images, dropdowns, colors, toggles, and numbers. Changes save automatically.
- **Complete macOS menus:** **File → New presentation…** (Cmd+N), a standard **Window** menu (Cmd+M), and a **Help** menu with documentation, release notes, a prefilled **Report a Problem…** form, and **Show Update Log**.
- **Move to Applications:** when launched from the DMG or Downloads, the app offers to move itself into Applications so automatic updates can install.
- **Full screen fixes:** Escape and closing a deck now only end a presentation started with **Present**; full screen entered with the green window button keeps the workspace visible.
- **Fresher slide state:** slide counts and thumbnails update promptly while files change.

### Upgrading

Installed 0.3.1 and later builds can receive this release through automatic updates. Use **Check for Updates** in Settings, then **Restart to Update** when ready, or quit normally and reopen the app after the update downloads. Users on 0.3.0 or earlier should install the DMG manually.

Because the app's name changes, **Restart to Update** from 0.4.1 or earlier installs the update and closes the app but does not reopen it. Open **Welcome to my Talk** from Applications once to finish; it replaces the old app there. Later updates restart normally. If Claude Desktop or Codex still shows the old name, choose **Connect** again and reinstall the extension or plugin.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.5.0-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.5.0-mac-x64.dmg`

Open the DMG, drag **Welcome to my Talk** into **Applications**, replacing the previous version if installed, then launch it from Applications. Node.js, npm, and a separate Git installation are not required.

The release also includes app ZIPs, blockmaps, and `latest-mac.yml` for automatic updates. Use the DMG for a manual installation.
