**Welcome to My TED Talk 0.2.0** uses the same purple T artwork for the macOS app and the Codex plugin.

- The app now displays its own icon in the Dock and Finder on both Apple Silicon and Intel Macs.
- The Codex plugin uses a shared SVG source, with instructions for regenerating the macOS packaging icon.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.2.0-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.2.0-mac-x64.dmg`

Open the DMG, drag **Welcome to My TED Talk** into **Applications**, replacing the previous version if installed, then launch it from Applications. Node.js and npm are not required.
