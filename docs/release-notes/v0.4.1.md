**Welcome to My TED Talk 0.4.1** makes everyday editing more convenient, adds branch controls, and improves update recovery and diagnostics.

### Features and improvements

- **Create and switch branches:** use the branch picker in the footer to choose an existing Git branch or create a new one for your deck.
- **More reliable focused AI edits:** a new exact text replacement tool changes a single unique match and rejects missing or ambiguous matches, helping AI make small edits safely.
- **A more compact workspace:** tighter heading, filmstrip, footer, and history spacing leaves more room for your slides. History timeline markers now align with the vertical line.
- **Simpler menus:** deck actions and connection options are grouped in the File and Connect menus.
- **Open Settings with a shortcut:** use the standard macOS **Cmd+,** shortcut.
- **Clearer update progress and recovery:** Settings badges show downloading, verification, ready, and error states. Download progress includes percentage and elapsed time where available. Temporary connection and server failures retry automatically; manual retry starts a fresh retry budget.
- **Better update diagnostics:** errors identify the failed update step, and **Show update log** reveals local diagnostic logs for troubleshooting. Sensitive URL and credential fields are redacted.
- **About panel credits:** the macOS About panel now credits the app's creator and MIT license.

### Upgrading

Installed 0.3.1 and later builds can receive this release through automatic updates. Use **Check for Updates** in Settings, then **Restart to Update** when ready, or quit normally and reopen the app after the update downloads. Users on 0.3.0 or earlier should install the DMG manually.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.4.1-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.4.1-mac-x64.dmg`

Open the DMG, drag **Welcome to My TED Talk** into **Applications**, replacing the previous version if installed, then launch it from Applications. Node.js, npm, and a separate Git installation are not required.

The release also includes app ZIPs, blockmaps, and `latest-mac.yml` for automatic updates. Use the DMG for a manual installation.
