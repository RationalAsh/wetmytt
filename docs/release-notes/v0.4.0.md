**Welcome to My TED Talk 0.4.0** adds more control over your slides and project files, clearer AI progress, and tools to inspect and recover your work.

### Features and improvements

- **Manage slides:** duplicate, delete, and move slides from thumbnail menus in new decks. Stable slide IDs keep selection consistent. Existing compatible JSON decks can opt in using the [slide management guide](https://github.com/RationalAsh/wetmytt/blob/v0.4.0/docs/slide-management.md).
- **Let AI inspect slide layouts:** ask built-in chat to inspect slides and fix layout problems. Image-capable models can view slide screenshots; providers that reject images fall back to text with a notice. Screenshots are sent to your configured AI provider for the current request.
- **Follow AI progress:** see elapsed time and the current operation during requests. OpenAI, OpenRouter, and Ollama stream text when supported; Claude and Gemini show progress while returning complete model turns.
- **Browse and save project files:** the Files sidebar shows the project tree and Git changes, with controls to stage, unstage, and commit your work.
- **Explore saved history:** view a commit history timeline and live Git status in the footer.
- **Restore with a backup:** Restore last save returns uncommitted files to the latest commit after preserving changes in a recoverable local backup. It does not undo completed commits; see the [restore guide](https://github.com/RationalAsh/wetmytt/blob/v0.4.0/docs/restoring.md).
- **Clearer update reminders:** a persistent restart banner makes downloaded updates easier to find.
- **More reliable AI edits:** malformed patches are rejected instead of being reported as successful edits.

### Upgrading

Installed 0.3.1 and later builds can receive this release through automatic updates. Use **Check for Updates** in Settings, then **Restart to Update** when ready, or quit normally and reopen the app after the update downloads. Users on 0.3.0 or earlier should install the DMG manually.

### Downloads

- **Apple Silicon (M1 and later):** `wetmytt-0.4.0-mac-arm64.dmg`
- **Intel Mac:** `wetmytt-0.4.0-mac-x64.dmg`

Open the DMG, drag **Welcome to My TED Talk** into **Applications**, replacing the previous version if installed, then launch it from Applications. Node.js, npm, and a separate Git installation are not required.

The release also includes app ZIPs, blockmaps, and `latest-mac.yml` for automatic updates. Use the DMG for a manual installation.
